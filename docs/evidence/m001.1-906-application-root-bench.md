# Baseline — #906 application-root action/snapshot cost

This is a first-record baseline, not a renderer or GPU claim (`performance_claim=false`).

## Conditions

- Hardware: Apple M5 Pro, 24 GiB, macOS 26.5.2 (25F84), Darwin 25.5.0 arm64
- Build: `cargo bench -p seyal-client --locked --bench app_root` (release/optimized)
- Workload: 8,000 bind+snapshot iterations per representative pane count
- Percentile method: nearest rank
- Base SHA at measurement: `94fa61254cdb4e1a76ff7146f89d53432f59ca56` (`remove-all-swift` + #905). Implementation SHA is the #906 PR head.
