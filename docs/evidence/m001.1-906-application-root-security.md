# Security review — #906 application root / versioned host API

Date: 2026-09-12
Issue: #906
Scope: `seyal-client` application root, versioned FFI, accessibility projection

## Assets

- One `TerminalExecution` / PTY / canonical `TerminalState`
- Controller vs observer attachment authority
- Pane / execution / attachment / presentation-epoch fencing
- Pointer-bearing snapshot and accessibility buffers
- Native effect signaling for quit/detach

## Actors

- Trusted in-process native host (future #883)
- Local Runtime over the existing Candidate-D UDS path
- No remote, plugin, or commercial caller in this slice

## Entry points

- Rust `ApplicationRoot::apply` / `attach_client` / `poll_client`
- C ABI `seyal_app_create` / `apply` / `snapshot` / `accessibility` / `destroy`

## Authorization

- Every pane-sensitive action carries an explicit fence. Unknown/stale Pane,
  ExecutionId, AttachmentId, controller bit, or presentation epoch fails closed
  and is not retried against a newer snapshot.
- Unbound identity cannot authorize Flow or Composer.
- Direct terminal input requires a bound controller and Raw/TUI eligibility
  derived from canonical evidence, not a host-selected mode.
- The root binds an existing `LocalDisplayClient`; it does not create a second
  PTY, VT, Runtime registry, or workspace database.
- Quit freezes input and emits a bounded detach/terminate effect. It does not
  kill surviving executions.

## Input validation

- ABI version/size mismatches fail closed.
- Null action/payload pointers fail closed.
- Non-UTF-8 submit payloads fail closed.
- Zero PTY generation cannot bind.

## Resource / lifetime

- Snapshot and accessibility pointers borrow handle-local buffers until the
  next mutating bridge call. No retain/release of Rust memory.
- Handles are explicit; unknown handles fail closed.
- Product snapshots stay off the PTY→VT hot path. Prepared frames remain the
  existing Candidate-D transfer.

## Residual risk

- The native host (#883) must copy snapshot bytes before the next mutating
  call and must not treat a stale generation as live authority.
- Cmd-Q native termination still belongs to the host; this slice only freezes
  and requests bounded cleanup.
- Composer draft/submit lifecycle remains #881; Flow eligibility is a
  read-only projection.
