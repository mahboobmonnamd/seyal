# Code of Conduct

## Our standard

Seyal is committed to a welcoming, technically rigorous community. Participants must treat one another with respect and must not engage in harassment, discrimination, personal attacks, intimidation, or deliberate disruption.

Constructive technical disagreement is welcome. Critique ideas and implementation choices, not people. Follow the security reporting rules when a report contains sensitive information.

## Enforcement

Report unacceptable behavior privately to the project maintainers through the contact method configured for this repository. Do not open a public issue for harassment or include private personal information in a report.

Maintainers may remove content, close discussions, restrict participation, or take other actions they consider appropriate to protect the community.

## Scope

This code of conduct applies in project spaces, issue trackers, pull requests, community discussions, and project-related events. It also applies when someone is representing Seyal in public.
